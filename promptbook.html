14개 요청 카드1·2·3교시 + 문제 해결

좋은 요청의 재료 네 가지

“멋진 전시관을 만들어 줘”는 사람마다 결과가 달라집니다. 아래 네 가지를 넣으면 결과를 검토할 기준이 생깁니다.

01대상

누가 사용할까?

02문제

어떤 불편을 줄일까?

03범위

이번에 어디까지 만들까?

04결과 형식

표, 코드, 설명 중 무엇이 필요할까?

먼저 지킬 세 가지

개인정보는 넣지 않기

실명, 학번, 연락처, 비밀번호, API 키는 요청문에 쓰지 않습니다. 닉네임과 아이디어만 사용합니다.

답은 초안으로 읽기

AI는 그럴듯하게 틀릴 수 있습니다. 사실·가격·기기 지원은 공식 자료나 직접 실행으로 확인합니다.

고친 부분을 기록하기

AI 초안에서 내가 바꾼 문장과 이유를 워크북에 남깁니다. 그게 내 작업의 증거입니다.

AI 답변 검토 체크리스트

P04와 함께 사용합니다. 검토 기록은 유지할 점 1개 + 고칠 점 1개 + 확인 필요 1개로 워크북 M2에 남깁니다.

  1. “항상”, “모든”, “완벽하게”처럼 근거 없이 단정한 문장이 있는가?
  2. 가격, 무료 여부, 기기 지원처럼 바뀔 수 있는 사실을 확인했는가?
  3. 내가 요청한 대상·문제·범위를 벗어난 내용이 섞였는가?
  4. “테스트 통과” 같은 결과를 실제로 실행해서 확인했는가?
  5. 코드라면 내가 바꾼 줄을 설명할 수 있는가?
  6. 출처가 필요한 내용에 출처가 있는가? 없다면 직접 찾았는가?
