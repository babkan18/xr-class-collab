디자인을 골랐다면, 이렇게 시작하세요.

  1. 미리보기로 화면과 프로젝트 상세창을 확인합니다.
  2. 원하는 디자인의 이 디자인 받기를 누릅니다. 파일명은 index.html입니다.
  3. 파일 맨 위 여섯 항목을 수정하고, 기존 개인 저장소의 최상위에 업로드합니다.
  4. Commit → GitHub Pages 배포를 진행합니다. 50분 실습 안내 열기 ↗

브라우저가 index (1).html처럼 저장하면 index.html로 이름을 바꿔 주세요. 디자인을 바꿀 때는 기존 파일의 MY_PROFILE 내용을 새 파일로 옮기세요.
