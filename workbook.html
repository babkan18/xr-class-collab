Fork와 PR 실습 순서

  4. 내 작업 브랜치에 Commit합니다.
  5. Contribute / Open pull request 또는 Compare & pull request를 엽니다. base는 chloeisLovely/my-xr-universe:main, head는 내계정/xr-class-collab:idea-내번호입니다.
  6. Files changed에서 내 파일 하나인지 확인합니다. 본문에 Refs #1과 검토 요청을 쓰고 Create pull request를 누릅니다.
  7. 친구 PR을 읽고 구체적 질문을 남깁니다. Merge는 강사가 진행합니다.
MISSION 03 · 3교시

나의 홈페이지 공개하기

디자인 3종 비교하기 · 수정할 내용은 모두 같습니다.

  1. 선택한 HTML을 내려받고 파일명을 index.html로 확인합니다.
  2. 텍스트 편집기로 열어 맨 위 MY_PROFILE 6개 항목만 수정합니다. P08을 참고합니다.
  3. 저장 후 브라우저로 열어 닉네임, 프로젝트, 버튼을 확인합니다.
  4. 개인 my-xr-universe 저장소 최상위에 index.html을 업로드하고 Commit합니다.
  5. Settings / Pages / Deploy from a branch / main / (root) / Save를 선택합니다.
  6. Actions가 성공한 뒤 Visit site를 엽니다. 반영에 최대 10분 정도 걸릴 수 있어 기다리는 동안 친구 작품을 검토합니다.

오늘 만든 결과는 XR 아이디어를 소개하는 웹 포트폴리오입니다. VR/AR 실행 기능 자체는 후속 프로젝트입니다.

파일 저장 여부, MY_PROFILE의 따옴표·쉼표·중괄호를 확인합니다. 브라우저를 새로고침하고 오류 메시지가 있으면 P09를 사용합니다. 전체 HTML을 AI 답변으로 덮어쓰지 않습니다.

404 / 이전 화면 / README가 보여요

내 개인 저장소의 main 최상위에 소문자 index.html이 있는지 확인합니다. 파일명이 index.html.txt가 아닌지 확인하고 Pages가 main/(root)인지 봅니다. Actions가 진행 중이면 기다린 뒤 강력 새로고침합니다. 저장소 주소와 github.io 웹 주소는 다릅니다.
