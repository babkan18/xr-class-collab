# my-xr-universe
XR 포트폴리오 · GitHub 실습 템플릿

강사용 배포 저장소입니다. 학생에게는 `student/index.html`을 배포하고, 학생 각자의 기존 저장소 최상위에 `index.html`로 업로드합니다. 루트 화면의 GitHub 링크는 강사 계정으로 연결됩니다.

> 닉네임과 프로젝트 설명을 나의 내용으로 바꾸세요.

## About me
- 닉네임: XR Explorer
- 관심 분야: VR
- 관심 기술: Unity, Blender, WebXR

## Project idea
나만의 가상 학교 전시관 — 학생들의 작품을 가상 공간에 전시하는 프로젝트.
현재 상태: 기획 중. 다른 두 프로젝트 카드는 참고 아이디어입니다.

## Website
GitHub Pages 활성화 대기 상태입니다. Settings → Pages에서 main / (root)를 선택한 뒤 표시되는 실제 주소로 접속하세요.

- [학생용 원본](student/index.html)
- [실습 시작 페이지](lab.html)
- [강사 예시](instructor/index.html)

GitHub 파일 화면은 코드 보기입니다. HTML 화면은 파일을 내려받아 열거나 Pages 활성화 후 확인합니다.

## 실행
`index.html`을 더블클릭하면 실행됩니다. API 키, 설치, 빌드 과정이 없습니다.
GitHub에서는 기존 `my-xr-universe` 저장소의 루트에 index.html을 업로드합니다.
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 수정
index.html 맨 위 MY_PROFILE의 6개 항목만 변경합니다.
자세한 절차: [학생 가이드](docs/STUDENT_GUIDE.md).
강사 예시: [instructor/index.html](instructor/index.html).
심화용 분리본은 advanced 폴더의 파일 4개를 함께 사용합니다.
