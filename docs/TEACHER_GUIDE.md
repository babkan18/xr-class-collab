# 강사용 운영 메모

## 수업 구조
- 1교시: 학생마다 `my-xr-universe` 저장소 하나 생성 → README → Commit.
- 2교시: 강사가 준비한 별도 팀 저장소에서 Issue, Branch, Pull Request 체험.
- 3교시: 같은 개인 저장소에 index.html 업로드 → 6개 항목 수정 → Pages → 재수정·공유.

수강생 11명, 50분 기준. 계정 가입·이메일 인증·학교망 접속은 수업 전에 확인해야 합니다.

## 배포 파일
- ZIP 루트 `index.html`: 학생용. 이것 하나를 기존 개인 저장소에 업로드.
- `instructor/index.html`: NOVA 강사용 예시. 실제 학생·제작 성과를 나타내지 않음.
- `advanced/index.html`, `styles.css`, `profile.js`, `app.js`: 심화용 분리 구조. 필수 수업에서는 사용하지 않음.
- `README.md`: 학생용 소개서 양식. 기존 README를 덮어쓰지 말고 필요한 내용만 반영.
- `docs/STUDENT_GUIDE.md`: 50분 단계별 지침.
- `lab.html`: 링크·체크리스트가 있는 실습 시작 페이지. 체크는 자기 확인용이며 실제 배포를 검사하지 않음.

## 시연 스크립트
“이 사이트의 주인은 여러분입니다. 오늘은 여섯 군데를 바꾸고, 그 변화가 기록되는 것을 확인합니다. 아직 만들지 않은 프로젝트는 기획 중으로 적습니다. 아이디어를 정직하게 설명하는 것도 포트폴리오의 실력입니다.”

“Commit은 저장 버튼에 설명을 붙이는 경험입니다. 이름만 쓰기보다 무엇을 바꿨는지 써 봅시다. 마지막에는 코드가 있는 저장소 주소와 실제 홈페이지 주소의 차이를 친구에게 설명해 주세요.”

## 완료 기준
1. 기본 닉네임·소개·대표 프로젝트를 자기 내용으로 변경.
2. 의미 있는 Commit 메시지 2개 이상과 변경 줄 확인.
3. Pages의 실제 공개 주소 확보, 친구 기기에서 접속.
4. 모바일 메뉴·프로젝트 상세창·GitHub 링크 정상.
5. 기본 예시 두 개는 참고 아이디어로 구분, 타임라인 계획·실행 구분.

## 운영 팁
- 25분까지 수정이 안 끝나면 필수 3개 항목만 먼저 마무리합니다.
- 늦은 학생에게 새 저장소를 만들게 하지 말고 기존 저장소를 함께 확인합니다.
- 공개 Repository에는 개인 정보·비밀번호·API 키를 넣지 않습니다.
- 네트워크가 막히면 로컬 HTML 시연을 완료하고, 공개 배포는 별도 완료 항목으로 남깁니다.
- 이 저장소의 루트와 강사용 데모는 chloeisLovely 계정으로 연결됩니다. 학생용 원본 student/index.html은 사용자명이 미설정입니다. 각자 ⑥을 설정합니다.

## 보너스 편집 위치
- 색상: `:root`의 CSS 변수. 상단 테마 버튼 변경은 브라우저 로컬 선택.
- 프로젝트 2·3: 스크립트 `projects` 배열. 기본 예시임을 알리는 상태 문구를 실제 작업 상태에 맞게 변경.
- 성장 기록: `journey` 배열. 완료하지 않은 활동에 완료 표기하지 않기.
- 저장소 이름: `REPOSITORY_NAME` 기본값은 `my-xr-universe`.
- 반응형: 760px 이하 단일 열, 모바일 메뉴. 움직임 최소화 설정 대응.

## 배포 범위
이 패키지는 GitHub Pages에 업로드할 수 있는 정적 소스입니다. 이번 작업의 별도 미리보기 호스팅은 GitHub Pages 등록 성공을 의미하지 않습니다. 사용자가 GitHub 저장소를 생성했고, 배포용 파일을 연결된 GitHub 도구로 등록합니다. GitHub Pages는 별도 설정이 필요하며 실제 배포 성공 후 확인합니다.

## 디자인 선택 수업 운영
0–5분에 templates.html에서 3가지 디자인을 비교하고 하나만 고릅니다. Cosmos는 우주형, Creative Studio는 밝은 전시형, Next Level은 네온 게임형입니다. 디자인을 고르는 데 3분 이상 쓰지 않도록 안내합니다. 파일은 모두 index.html이며, 수정할 MY_PROFILE 항목과 Commit·Pages 절차는 동일합니다. 게임형도 성장 기록은 계획이며 실제 완료 이력을 자동 조회하지 않습니다.
