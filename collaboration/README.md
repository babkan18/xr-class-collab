개인 포트폴리오 저장소는 `my-xr-universe`입니다. 이 저장소를 Fork할 때 이름을 `xr-class-collab`으로 바꿔 충돌을 피하세요.
내 Fork에서 `idea-01`처럼 번호별 브랜치를 만들고 `ideas/student-01.md`처럼 자기 파일 하나만 수정합니다.
Commit 후 원본 `chloeisLovely/my-xr-universe:main`으로 PR을 보냅니다. 본문에 `Refs #1`을 넣습니다. 공동 이슈에 `Closes #1`을 사용하지 않습니다.
Files changed에서 내 파일 하나만 바뀌었는지 봅니다. 친구 PR의 내용에 구체적인 피드백을 남기고 Merge는 강사가 진행합니다.

## 강사용 예시 (실제 학생 작품이 아님)
- 닉네임: NOVA
- 프로젝트 제목: 교내 작품 가상 전시관
- 대상: 다른 학과 작품이 궁금한 신입생
- 불편: 작품을 볼 장소와 시간이 제한됨
- XR 경험: 가상 전시 공간에서 작품을 선택해 설명을 읽음
- 첫 실험: 종이 화면으로 전시 동선을 친구 2명에게 설명하고 길을 찾는지 관찰
- 현재 상태: 기획 중
- 질문: 처음 들어온 사람에게 어느 작품을 먼저 보여주면 좋을까요?

## 강사 리뷰 기준
대상과 불편이 연결되는가? 첫 실험이 작은가? 개인정보가 없는가? 자기 파일만 바꿨는가?
승인할 때 실제로 읽은 부분만 언급합니다. PR이 merge되어도 전체 Issue는 수업 종료 전까지 열어 둡니다.
