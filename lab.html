GITHUB LAB / 50 MINUTE MISSION

나의 첫 XR 세계,
여섯 번의 수정으로 시작.

세 가지 디자인 중 나의 스타일을 고르고, 한 개의 저장소에 저장하고, GitHub Pages로 공유합니다.

디자인 3종 고르기 ↗기본 Cosmos 파일 받기 ↓강사용 예시 ↗학생용 미리보기 ↗
01 / 0–10 MIN

내 저장소에 파일 추가

3가지 디자인 중 하나를 선택한 뒤 1교시에 만든 my-xr-universe를 엽니다. 선택한 index.html을 저장소 최상위에 업로드합니다. 새 개인 저장소를 또 만들지 않습니다.

02 / 10–20 MIN

여섯 항목 개인화

파일 맨 위 MY_PROFILE에서 닉네임 · 소개 · 관심 분야 · 기술 3개 · 프로젝트 · GitHub 아이디를 수정합니다. 따옴표와 쉼표는 남겨 두세요.

03 / 20–25 MIN

변화를 Commit으로 기록

Personalize nickname and project idea처럼 무엇을 바꿨는지 씁니다. History에서 변경된 줄을 확인합니다.

04 / 25–35 MIN

GitHub Pages 배포

Settings → Pages → Deploy from a branch → main + /(root) → Save. Actions 성공 후 Pages에 표시된 실제 주소를 엽니다.

05 / 35–45 MIN

다시 수정하고 공개

한 줄 소개나 기본 색상 변수를 바꾸고 새 Commit을 만듭니다. 배포 완료 후 바뀐 화면을 확인합니다. 테마 버튼의 선택은 내 브라우저에만 저장됩니다.

06 / 45–50 MIN

친구의 화면에서 확인

사이트 주소를 공유하고 휴대전화에서 메뉴, 프로젝트 상세창, GitHub 링크를 확인합니다. 저장소 주소와 홈페이지 주소의 차이를 설명해 보세요.

나의 완료 체크

직접 확인한 뒤 체크하세요. 이 체크리스트는 배포 상태를 자동 검사하지 않으며 현재 브라우저에만 저장됩니다.

막히면 여기부터

404 오류가 나요.

파일명이 소문자 index.html인지, main의 루트에 있는지, Pages source가 main + /(root)인지, Actions가 성공했는지 확인합니다. ZIP 자체를 올리면 페이지가 생기지 않습니다.

수정한 내용이 화면에 안 나와요.

MY_PROFILE의 따옴표·쉼표를 확인하세요. Commit과 배포가 완료되었는지 확인한 후 새로고침합니다.

GitHub 버튼이 안내만 보여요.

⑥ githubUsername에 주소 전체가 아닌 본인 아이디만 입력합니다. 저장소명이 다르면 REPOSITORY_NAME도 수정합니다.

심화 미션을 하고 싶어요.

:root의 색상 변수를 바꾸거나 projects 배열의 예시를 개인화해 보세요. HTML/CSS/JS 분리본도 준비되어 있습니다. 성장 기록은 실제 수행한 내용만 완료로 표시하세요.

실명·연락처를 요구하지 않습니다. 기본 프로젝트는 기획·참고 아이디어입니다.
